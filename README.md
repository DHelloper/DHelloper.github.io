# Backend Developer Blog

Java · Spring · PostgreSQL · Redis를 중심으로 실무 문제를 직접 실험하고 기록하는 기술 블로그입니다.

## 시작
```bash
npm install
npm run dev
```

## GitHub Pages
1. Repository를 `YOUR_GITHUB_ID.github.io`로 생성
2. `astro.config.mjs`의 `YOUR_GITHUB_ID` 변경
3. GitHub → Settings → Pages → Source를 **GitHub Actions**로 설정
4. `main`에 push하면 자동 배포

## 글 작성
`src/pages/posts/` 아래에 `.md` 파일을 추가합니다.

추천 흐름:
**문제 → 이론 → 구현 → 실험 → 측정 → 분석 → Trade-off → 면접 질문 → 결론**
